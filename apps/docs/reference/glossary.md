# Glossary

| Term | Meaning |
|------|---------|
| **Definition** | Versioned schema for an entity or component |
| **Effective model** | Resolved field set after composition |
| **Environment** | Isolated runtime slice of a project |
| **Data plane** | Runtime record APIs (`/data/v1`) |
| **Platform API** | Control-plane HTTP (auth, schema, access, …) |
| **Role binding** | Links a principal to a role |
| **Policy** | PBAC allow/deny rule |
| **Process** | Durable workflow definition |
| **Function** | Invocable code hook (stub runtimes today) |
| **Plugin / addon** | Capability-based Host extension |
| **Credential** | `morph_sk_…` project API key |
| **Governed SQL** | Allowlisted SQL query endpoint |
| **Dev Panel** | Browser console over `@morph/sdk` |
