# SDKs

Official clients wrap Morph HTTP APIs.

| Package | Language | Path |
|---------|----------|------|
| `@morph/sdk` | TypeScript / JavaScript | `sdks/typescript` |
| `Morph.Client` | .NET | `sdks/dotnet/Morph.Client` |

Both support login, tenancy helpers, definitions, data CRUD, files, GraphQL/SQL, access, processes, functions, webhooks, SMS, and plugins listing.

The **Dev Panel** depends only on `@morph/sdk` — if the panel can do it, the SDK can do it.
